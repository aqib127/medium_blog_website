# Auth & Users Domain (blog_backend/users)

Authentication, user profiles, and follow system. Custom user model + JWT auth.

## Models (`users/models.py`)
- `User(AbstractUser, BaseModel)` — custom `AUTH_USER_MODEL`. `username = None`; login identifier is **email** (`USERNAME_FIELD = 'email'`, unique), with `name` required. Adds `handle` (unique), `bio`, `location`, `twitter`, `github`, `website`, `avatar` (`avatars/`), `avatar_color`, denormalized counters (`followers_count`, `following_count`, `articles_count`).
- `UserSettings` — OneToOne to `User` (email/push notifications, dark_mode, preferences JSON). Auto-created via `post_save` signal on `User`.
- `Follow` — follower/followed FKs; drives `followers_count`/`following_count` via signals.

## Custom User Model note
`User` extends Django's `AbstractUser` plus the project `BaseModel`. Creation goes through `UserManager` (`users/managers.py`), which requires an `email` and sets the password; pass `handle` via `extra_fields`. `handle` is not auto-generated by the manager — the calling code/registration flow must supply it (and must keep it unique).

## URL routes
- `users/urls.py` — auth: `register`, `login`, `refresh`, `verify`, `logout`, `me`.
- `users/urls_profile.py` — profile by `<handle>`: profile, `stories`, `followers`, `following`, `follow` (toggle), `update`, `avatar`.

## Views (`users/views.py`)
`UserProfileView`, `UserStoriesView`, `FollowersView`, `FollowingView`, `FollowToggleView`, `ProfileUpdateView`, `AvatarUpdateView` (plus auth views).

## Signals
Follow/unfollow and article-creation must update the denormalized `followers_count` / `following_count` / `articles_count` via signals (see `users/signals.py`) so profile pages stay accurate.

## Frontend counterpart
`AuthContext` (login/logout/me), `utils/apiClient.js` (token refresh). Endpoints: `users`, `userStories`, `userFollowers`, `userFollowing`, `userFollow`, `userUpdate`, `userAvatar` in `blog_frontend/src/config/api.js`. Components: `Profile`, `ProfileStories`, `ProfileSettings`, `FollowList`, `Avatar`.
